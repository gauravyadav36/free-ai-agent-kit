# Research

Structured research outline on any topic, with checks.

## Steps
1. State what it is in one plain paragraph.
2. Find one dated fact with a primary source.
3. Steelman both sides: supporters and critics, with what would prove each wrong.
4. List risks and unknowns openly.
5. Name the single next source to read before deciding.

## Rules
- Distinguish confirmed facts from claims.
- Never cite a source you did not read.
